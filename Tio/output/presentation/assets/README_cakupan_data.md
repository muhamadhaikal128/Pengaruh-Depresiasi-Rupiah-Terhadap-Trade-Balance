# Arti cakupan pada aset presentasi

Semua nilai ekspor dan impor adalah milik Indonesia. WLD/World/dunia menunjukkan negara mitra secara agregat; kolom ISO3 pada panel menunjukkan mitra. File world_annual_USDbn.csv adalah perdagangan tahunan Indonesia dengan seluruh dunia, bukan ekspor/impor global. File partner_trade_2025.csv adalah perdagangan Indonesia dengan sepuluh mitra.

Satuan aset tahunan, bilateral, dan kelompok adalah USD miliar, dengan akhiran kolom USDbn. Reporter ditulis eksplisit sebagai Indonesia. Partner_ISO3 menunjukkan negara mitra. Perbaikan nama kolom tidak mengubah nilai yang digunakan dalam grafik. Dataset intermediate yang berakhiran USDk tetap benar-benar bersatuan USD ribu.

Statistik jcurve_point_pattern_counts_primary.csv menghitung model Indonesia pada berbagai cakupan, bukan kumpulan model dari berbagai negara pelapor. Lihat ../scope_audit_indonesia.json.
